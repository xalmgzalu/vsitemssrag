# RAG evaluation harness

`rag_cases.json` — небольшой живой набор пользовательских сценариев. Для каждого
кейса запускайте команду `ask` и оценивайте ответ по полю `review`:

```bash
uv run vsitemssrag ask "Я новичок, бюджет до 6000 ₽, хочу контрольное основание"
```

Unit-тест проверяет структуру набора и детерминированные ограничения вроде
бюджета. Смысл и полезность рекомендации пока оценивает человек: это честнее,
чем просить ту же модель выставлять оценку самой себе.

Добавляйте реальные формулировки пользователей как отдельные кейсы. Хороший
регрессионный набор содержит вопрос, жёсткие машинно-проверяемые ограничения и
краткое описание ожидаемого поведения, но не фиксирует ответ слово в слово.
